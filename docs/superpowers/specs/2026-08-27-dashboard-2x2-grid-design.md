# 看板 2×2 网格布局设计

日期：2026-08-27
状态：待用户审阅

## 背景

看板新增「路径统计（Top 10）」面板后，以横跨整行的横幅形式挂在网格下方，导致整页高度上升、视觉上与现有网格脱节。本次将其融入看板网格，并把「最近请求」一并并入网格，形成 2×2 布局，使看板接近一屏完整展示。

## 现状布局

```
[5 张统计卡片]
┌──────────────────────┬──────────────┐
│ 访问趋势（24 小时）    │ 域名分布      │
└──────────────────────┴──────────────┘
┌─────────────────────────────────────┐
│ 路径统计（Top 10）← 新增，横跨整行   │
└─────────────────────────────────────┘
[提示行]
[最近请求（整行）]
```

## 目标布局（方案二）

```
[5 张统计卡片]（不变）
┌──────────────────────┬──────────────┐
│ 访问趋势（24 小时）    │ 域名分布      │
├──────────────────────┼──────────────┤
│ 最近请求              │ 路径统计 Top10 │
└──────────────────────┴──────────────┘
[提示行]（不变）
```

- 左列 = 时间维度（24 小时趋势 + 最新流水）
- 右列 = 分布维度（域名分布 + 路径分布）
- 实测整页高度约 1029px（1440×1000 窗口、演示数据口径），较改动前 1281px 明显下降；
  1000px 视口基本一屏，1080p 浏览器（内容区约 950px）轻微滚动

## 改动点

### 1. public/index.html

- 「最近请求」面板（`.dash-recent`）从 `dash-grid` 外移入 `dash-grid` 内，作为最后一个子面板
- `dash-grid` 内 DOM 顺序保持：访问趋势 → 域名分布 → 路径统计 → 最近请求
- 提示行保持在 `dash-grid` 之后，位置不变

### 2. public/style.css

- 移除 `.dash-paths` 的 `grid-column: 1 / -1` 整行规则
- 下排两面板**行、列全部显式指定**：`.dash-paths { grid-row: 2; grid-column: 2; }`、
  `.dash-recent { grid-row: 2; grid-column: 1; }`
  —— 稀疏自动放置的游标会越过左列第二行（实测只定 `grid-column: 2` 时最近请求落到第三行），
  完全确定的位置不依赖游标
- `.dash-recent` 内的列表改为纵向均分（`justify-content: space-around`），
  消化与右侧路径统计面板的高度差
- 轻度压缩贴近一屏：路径条形行距 7px→5px、域名图例 `max-height` 200px→160px、
  环形图 CSS 缩放 150px→120px（图例列宽同步 154px→124px）
- 其余网格规则不动（`grid-template-columns: 2fr 1fr` 保持）

### 3. 移动端（≤1080px 单列）

- 现有媒体查询中补充 `.dash-paths, .dash-recent { grid-row: auto; grid-column: auto; }` ——
  单列网格下显式列位会隐式创建第二列，必须复位
- 复位后顺序为：趋势 → 域名分布 → 路径统计 → 最近请求，分布在前、流水殿后，阅读连贯。

### 4. 不改的部分

- `public/dashboard.js` 所有渲染函数（renderTrend / renderMainDomains / renderRuleHosts / renderPaths / renderRecent）与事件绑定零改动
- `src/stats.js` 的 `byPath` 聚合、`/api/stats` 接口、`test/stats.test.js` 零改动

## 数据流

不变：`/api/stats` → `requests.byPath`（`{ path, count, misses }`，次数降序 Top 10）→ `renderPaths` 渲染条形列表，未命中行标红 + 红徽章。

## 边界与风险

- **行高对齐**：第 2 行高度由路径统计（10 行）与最近请求（5 行）中较高者决定；
  最近请求留白由列表均分消化，视觉透气
- **域名图例长列表**：已有 `max-height` 滚动兜底（现状行为，不引入新问题）
- **趋势图拉伸**：行高由右侧面板决定时趋势 SVG 随之纵向拉伸，
  `preserveAspectRatio="none"` 与现状一致，比例变化小，文字变形可接受（现状即如此）
- **URL 截断**：最近请求从整行变半宽，URL 省略号截断稍早；完整记录在「请求记录」页，可接受

   - 路径面板未命中标红、条形比例正确
